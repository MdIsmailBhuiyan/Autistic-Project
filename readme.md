## Project Overview
This project focuses on early detection of autism in children using **deep learning**. The application allows users to:

1. **Predict autism** based on facial images.
2. **Display confidence scores** for predictions.
3. **Visualize model attention** using Grad-CAM, Grad-CAM++, and Eigen-CAM.  

The goal is to provide an assistive tool for research and awareness in autism spectrum disorder (ASD).

---

## Features
- **Autism Detection**: Classifies children as autistic or non-autistic based on images.
- **Confidence Score**: Shows the probability of the prediction.
- **Multiple Visualizations**: Grad-CAM, Grad-CAM++, and Eigen-CAM to interpret model decisions.
- **Easy-to-Use App**: Upload an image and get results with visual explanations.
